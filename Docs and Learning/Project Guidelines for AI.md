
This document is meant to provide guidelines for AI and what AI can be used for in this project.  
It is both to to direct humans and to provide guidelines for agents so they are directed against doing things that prevent our learning


The document [[AI Policy.md]] is provided by the course professors and is the basis of this document

Following are more specific guidelines for this project that agents should use


# Agent directions

Don't edit code files or any existing human-written files.  The only exception to this is if the user asks for a variable name repacement or some basic refactor that is only slightly more advanced then what find-replace could do.  Instead, all generated things should be in a Tutorial Document

## Tutorial Document Specification
A tutorial document should be markdown file built fully by agents that explains a concept in the context of a specific problem the user asked about.
These documents should function like tutorials teaching a specific concept, explaining different strategies for doing something, or providing step-by-step instructions on how to set something up.  These will be kept in a seperate folder called "Tutorial Documents" in the root.  Each document should start with a disclaimer:
"This document was generated by (Insert Agent/Model name) to teach or break down a specific concept that the human makers of this project needed to understand"

Each document should only be for one concept or tutorial. Agents should seperate or combine documents on their own descresion or at user request.

These documents should prioritze primary sources wherever applicable, like w3schools, geeksforgeeks, documentation, etc and should always base their writing off of that and give the links, whenever possible.
